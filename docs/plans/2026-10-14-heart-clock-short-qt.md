# Часы сердца: синдром короткого интервала QT

Дата: 14.10.2026
Статус: принята автономно (режим «Все автономно»). Запрос пришёл от потока статей после влития статьи `short-qt-syndrome` (#398).
Свидетельства: `/mnt/project-files/evidence/short-qt-syndrome.md`, строки 16–19 и 30, разделы «Sources differ» и «ECG preset».

## Зачем

Статья о синдроме укороченного QT вышла без часов сердца. Ни один пресет не подходит: у нормы QTc 400 мс, а это не укороченный QT ни по одному источнику.

## Пресет `short-qt-syndrome`

| Параметр | Значение | Источник |
| --- | --- | --- |
| `qtc` | 320 | ESC 2022: при QTc ≤ 320 мс диагноз следует рассмотреть (IIa C). Шкала Gollob в Минздраве 569_2 даёт баллы за QTc < 330 мс. NICE CG109: короткий QTc — меньше 350 мс. Значение 320 — допущение на уровне ESC. |
| Частота | частота читателя, 40–180 | Как у пресета удлинённого QT: QT считается из QTc 320 мс по формуле Базетта (×√RR), поэтому QTc одинаков при любой частоте. |
| Форма зубца T | по умолчанию | Источники не дают чисел для формы T. |

- Группа «Нарушения ритма», сразу после удлинённого QT. `presetShape` = null.
- Описание (`summary`) говорит, что одного порога для диагноза нет: пороги примерно от 316 (у людей младше 20 лет, Минздрав) до 370 мс используют вместе с жалобами, семейным анамнезом и генетикой. Оно говорит, что 320 мс выбраны для модели и что опасные аритмии модель не показывает.
- Без советов о лечении и без самодиагностики по числу.

## Статьи

Через поток интерактива: в статье `short-qt-syndrome` пресет `short-qt-syndrome` рядом с нормой, чтобы QT можно было сравнить.

## Тесты

- QTc 320 мс при каждой частоте 40–180, QT короче нормы при той же частоте; диапазон частот не сужается (unit-тест рядом с удлинённым QT).
- Пресет помещается в полоску при любой частоте.
- Снимки кривых: добавляются только записи нового пресета.
- e2e: пресет в группе «Нарушения ритма», описание ЭКГ с частотой, axe без нарушений.
